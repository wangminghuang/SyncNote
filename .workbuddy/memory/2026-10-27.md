# 2026-10-27

## SyncNote 项目初始化完成

**需求**：原生 Android app，输入 GitHub 仓库链接 + 选择本地目录 + 同步按钮，把仓库 clone/更新到手机本地目录（如 `.../tmp/Notes`）。

**技术选型（已定）**
- Kotlin + Jetpack Compose，包名 `com.example.syncnote`，minSdk 26 / targetSdk 37 / compileSdk 37
- Git 引擎：JGit `5.13.3.202401111512-r`（5.x 而非 6.x，后者依赖 Java 11 API 在 Android 上易编译失败）
- minSdk 必须 ≥ 26：JGit 用到 `java.nio.file`，该包 API 26 才引入
- 目录访问：`MANAGE_EXTERNAL_STORAGE`（所有文件访问权限）拿真实 File 路径给 JGit 写；不用 SAF，因为 `content://` URI JGit 不接受
- 同步语义：目录无 `.git` → clone（浅克隆 setDepth(1)）；已有 `.git` → fetch + reset --hard origin/HEAD

**环境事实**
- Android SDK: `D:\android-studio-sdk`
- 工具链模板给出 AGP `9.6.0-alpha01` + Gradle 9.6.0（都已是缓存版本，实测可用）
- 新模板无 `org.jetbrains.kotlin.android` 插件（AGP 9 内置 Kotlin 支持），不要手动加
- `INTERNET` 权限模板不生成，必须手写进 manifest

**踩过的坑**
1. 模板 `compileSdk 37` 但机器只装到 android-36.1 → 构建失败 `platforms;android-37.0` 缺失，AGP 自动下载失败。装了 SDK Platform 37.0 后正常。
2. 降 `compileSdk 36` 不可行：模板自带 `androidx.core:core-ktx:1.19.1`、Compose BOM 2026.02.01 强制要求 compileSdk ≥ 37。
3. build-tools 只有 36.0.0，未装 37.0.0 —— 实测不影响构建，AGP 自己选了可用版本。

**验证结果**：`./gradlew :app:assembleDebug` BUILD SUCCESSFUL，产物 `app/build/outputs/apk/debug/app-debug.apk` (12MB)。

**下一步待做**

- AndroidManifest 加 `INTERNET` + `MANAGE_EXTERNAL_STORAGE`
- 写 `MainActivity.kt`（输入框 + 选目录 + 同步按钮 + 状态）与 `GitSync.kt`（clone/fetch 逻辑，Dispatchers.IO）
